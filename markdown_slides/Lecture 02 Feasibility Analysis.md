# Key Ideas
Feasibility analysis guides the organization in determining whether to proceed with the project
Also identifies the important risks associated with the project that must be managed if the project is approved
Each organization has its own process and format for the feasibility analysis
Most include techniques to assess three areas: technical feasibility, economic feasibility, and organizational feasibility

# Break-Even point
Length of time when returns will match amount invested
Greater time -> Greater risks
Easier to picture graphically – plot cumulative present value of benefits and costs for each year

How to calculate Number of years of negative cash flow?

Step 1: Find the number of cumulative net cash flow, N [here N = 3]
Step 2: Look at initial year Total benefit.
		if benefit present then N unchanged
		if No benefit then N = N-1 [No benefit so N = 3 - 1 = 2]

# Present Value Calculation
PRESENT VALUE EQUALS
Cash flow amount
         Divided by

(1 + interest rate)n
Where “n” equals the number of periods
$100 received in 3 years with a required rate of return of 10% has a PV of $75.13.

Identifying the business value of the new project is a key to success
The system request describes an overview of the proposed system.
The feasibility study is concerned with ensuring that technical, economic, and organizational benefits outweigh costs and risks
